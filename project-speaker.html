Field Notes

前期调研

桌面音箱的竞品不是音箱，是台灯、显示器支架和收纳盒——它占的是桌面上「一件家具」的位置，不是「一台电子设备」的位置。

FACT

在售桌面音箱按外壳分三类：全塑料一体、木质箱体 + 金属格栅、织物包裹。木质 + 金属的组合集中在千元以上的家居化产品线。

电商在售页与厂商官网可见（2026-11 自查）
FACT

木质箱体几乎都是闭合箱；金属格栅以竖条或圆孔为主，竖条在追求开口率的产品上更常见。

同上，按外观可直接判读
INFERENCE

桌面用户对「像不像家具」的敏感度高于对参数的敏感度，因为箱体长期停在视线内。

由摆放场景反推，尚未做用户访谈
INFERENCE

侧面旋钮优于正面按键：正面要保持整块格栅的连贯，交互只能让到侧面。

Form & Detail

形态与细节

竖向格栅是本项目的核心形态决策：它同时承担声学开口、结构与视觉节奏三重角色。铝条间距按等分节奏排布，从正面形成稳定的竖向韵律，让箱体在桌面上「立得住」。

旋钮区是唯一的交互面：两枚金属旋钮配分段式蓝色光带，音量与声道状态一眼可读。侧板提供黑胡桃木与全黑两种材质对位——木质款偏家居，黑色款偏监听。

Form Axis / 分叉轴 · 木箱体与铝格栅的接缝归谁

侧板是实木、正面是铝格栅——两种材料的接缝，决定了它在桌面上到底是「设备」还是「家具」。分叉只围绕一件事：谁在外侧包住谁。

  • 声学 — 开口率 ≥ 52%，格栅—障板间隙 ≤ 1.2mm
  • 工艺 — 木质侧板不做深槽铣削（成本 +40%）
  • 桌面感 — 正视面不超过三种材质切边
A
木箱包住格栅

木侧板要一次深槽铣削，哑光漆在槽口最易积灰。

B
铝框 C 形包裹

铝框在前脸转折后绕到侧面收口，把接缝全部推出正视面。

C
卡扣可拆格栅

0.8mm 的可拆缝在正面留下第二条分割线，且要额外做卡扣模具。

D
全织物包裹 + 木顶板

网布遮蔽高频，透声率随湿度变化，声学不可控。

E
铝一体框 + 双色分界

去掉木质后跨到了另一个品类（蓝牙音箱），与「木质书桌」语境断开。

✓
SELECTED 铝框 C 形包裹

铝框在四角收成 C 形，把木材与格栅的接缝藏到侧面——正面只剩一条轮廓线和两枚旋钮。

Project Summary

让音箱回到家具

桌面监听音箱的设计不堆参数，而是回答一个更朴素的问题：一件电声产品，怎么在桌面上站得住、像家具。竖向格栅建立秩序，木质侧板拉回温度，铝框 C 形包裹把两种材料的接缝藏到侧面——一套模具，两种身份。
